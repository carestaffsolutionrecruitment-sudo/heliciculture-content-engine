# Module 5 Downloadable: Harvest and Processing Batch Record

**Commercial Heliculture Masterclass · Snail World (snailworld.org)**
**Format:** one A4 form per batch (two pages), plus a matching spreadsheet tab for the batch register. Keep it for at least 2 years. The Batch ID must appear on every container, label and invoice.

**Batch ID format:** `[farm code]-[species code]-[harvest date YYMMDD]-[sequence]`, e.g. `SW-CA-261003-01` (CA = *Cornu aspersum*, AM = *Archachatina marginata*, AA = *Achatina achatina*).
