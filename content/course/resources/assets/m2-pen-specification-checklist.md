## Section A: Escape-Proofing

|---|---|---|---|---|
| A1 | Lid or cover mesh aperture, hatchling units | ≤ 1–2 mm | | |
| A2 | Lid or cover mesh aperture, grower and breeder units | ≤ 3–5 mm (smaller than the smallest snail's shell) | | |
| A3 | Lids secured | Latched or clipped, not loose weights; no gap larger than A1 or A2 | | |
| A4 | Outdoor perimeter burial depth | 20–30 cm below ground | | |
| A5 | Outdoor perimeter height | 50–70 cm above ground | | |

## Section B: Drainage

| # | Criterion | Specification | ✅ / ⚠️ / ❌ | Measured / notes |
|---|---|---|---|---|
| B1 | Indoor floor fall to drain | ~1–2 % (1–2 cm per metre; about 0.5–1°) | | |
| B2 | Outdoor bed and pen surface fall | ~1–3 % away from pens; no hollows collecting run-off | | |
| B3 | Trench or bed base | 5–10 cm gravel drainage layer beneath the substrate | | |
| B4 | Standing water after irrigation or misting | None visible after 30 minutes | | |
| B5 | Run-off diversion | Rainwater diverted away from trench and pen openings | | |

**Slope formula:** fall % = (height difference in cm ÷ run length in cm) × 100. Angle ≈ fall % × 0.573°.

## Section C: Substrate

| # | Criterion | Specification | ✅ / ⚠️ / ❌ | Measured / notes |
|---|---|---|---|---|
| C1 | Depth, *Achatina* units and laying pots | 10–20 cm | | |
| C2 | Depth, *Cornu* growing boxes | 5–10 cm | | |
| C3 | Composition | Friable loam or loam–coir; ~5–10 % organic matter; no stones, clay lumps or pesticides | | |
| C4 | pH | 7.0–8.0. Test 3 samples per unit with a calibrated meter or kit (1:2 soil-to-distilled-water slurry) | | |
| C5 | Moisture | Holds together when squeezed; no free water | | |
| C6 | Sterilisation | Heat-treated or sterilised before use; date recorded | | |

**pH test method:** mix 1 part substrate with 2 parts distilled water, stir, rest for 30 minutes, then read with a calibrated meter. Correct anything below pH 7.0 with ground limestone, mix it in, and retest after 7 days.

## Section E: Micro-Climate Sensors

| # | Criterion | Specification | ✅ / ⚠️ / ❌ | Notes |
|---|---|---|---|---|
| E1 | Sensor height | At stock level (inside or at box height), not at ceiling or controller height | | |
| E2 | Sensor siting | Shaded, out of direct misting spray and sunlight; away from heaters and doors | | |
| E3 | Density | At least 1 temperature/RH logger per room or per 50 m² of pens, plus 1 per climate zone (e.g. top and bottom rack) | | |
| E4 | Calibration | Checked against a reference instrument within the last 3 months | | |
| E5 | Alarms (indoor) | Out-of-range and power-failure alarms tested this quarter | | |
| E6 | Targets posted | Species targets displayed in the unit (*Cornu* 18–22 °C / 75–90 % RH; *Achatina* 24–28 °C / 80–95 % RH) | | |
